Mi portafolio personal como programador — presentación, perfil y proyectos, todo en una página estática.

## ✨ Secciones
- **Home** con presentación personal ("Hola! Soy Ronaldo Gutierrez — Programador")
- Estilos propios en `styles/`

## 🚀 Cómo verlo
Abre `index.html` directamente en el navegador — no necesita servidor ni dependencias.

```
git clone https://github.com/RoDeluxe/Portafolio-Web.git
cd Portafolio-Web
# abre index.html con doble clic
```

## 🗂 Estructura
```
index.html        página única del portafolio
styles/           hojas de estilo
```
